# 🧾 견적서·보고서 자동 생성기

> 💼 **외주 문의 환영** — 위시켓·크몽에서 "김동진"으로 검색하세요. 작동하는 데모로 먼저 보여드립니다.

항목을 입력하면 **합계·부가세 자동 계산부터 PDF 출력까지 원클릭으로 처리**하는 업무 자동화 도구입니다.
모든 처리는 로컬에서 수행되며 외부 서버로 데이터가 전송되지 않습니다.

**이런 분께 필요합니다**: 견적서·발주서 반복 작성에 시간을 쓰는 중소기업, 프리랜서, 자영업자

---

> **시연용 프로토타입**입니다. 중소기업의 반복 문서 작업(견적서 작성·데이터 요약 보고)을
> 자동화하면 어떤 효과가 있는지 5분 안에 직접 체험할 수 있도록 만든 데모입니다.
> 실제 상용 구축 시 필요한 보안·권한·연동 요소는 포함되어 있지 않습니다.

## 1분 만에 실행하기

```bash
bash run.sh
```

- Python 3.10+ 필요. 첫 실행 시 `requirements.txt`의 패키지를 자동 설치합니다.
- 브라우저에서 **http://127.0.0.1:5000** 접속 (종료: `Ctrl+C`)
- 모든 처리는 로컬에서 수행되며, 외부 서버로 데이터가 전송되지 않습니다.

## 5분 시연 시나리오

| 시간 | 시연 내용 | 확인할 포인트 |
|------|-----------|--------------|
| 0:00–0:30 | 대시보드 → **🧾 견적서 만들기** 클릭 | 첫인상: 무엇을 하는 제품인지 3초 만에 파악 |
| 0:30–1:30 | `/quote/new?sample=1` — 예시 품목이 채워진 화면. 수량·단가를 바꿔보기 | 합계·부가세 10%가 **실시간 자동 계산**됨 |
| 1:30–2:30 | **견적서 생성 →** 클릭 → 생성된 견적서 확인 → **⬇ PDF 다운로드** | 회사 로고·정보·조건 문구가 들어간 정식 양식, 인쇄용 CSS |
| 2:30–3:30 | **📊 보고서 만들기** → `sample_data/sample_sales.csv` 업로드 | 숫자 컬럼 합계·평균·최대/최소, 거래처별 막대 차트 자동 생성 |
| 3:30–4:15 | **⚙ 템플릿 설정**에서 회사명·로고·조건 문구 변경 후 새 견적서 생성 | 템플릿 변경이 신규 견적서에 즉시 반영 (기존 문서는 생성 시점 정보 유지) |
| 4:15–5:00 | **문서 목록**에서 다시 보기·HTML/PDF 다운로드·삭제 | 문서 라이프사이클 관리 |

**예시 파일**: `sample_data/sample_quote_items.csv` (견적 품목 예시),
`sample_data/sample_sales.csv` (매출 데이터 18행 — 보고서 시연용)

## 기능 목록 (전부 실제 동작)

1. **견적서 자동 생성** — 품목(품명·규격·수량·단가) 입력 → 공급가액·부가세 10%·합계 자동 계산
   → 회사 로고/정보/조건 문구가 포함된 인쇄용 견적서 출력 (화면 보기·인쇄·PDF·HTML 다운로드)
2. **Excel/CSV → 요약 보고서** — 파일 업로드 → 행·열 수, 숫자 컬럼별 합계·평균·최대·최소,
   상위 항목 표 + 막대 차트 자동 생성 (UTF-8/CP949 인코딩 자동 인식)
3. **템플릿 관리** — 회사명·대표자·사업자번호·주소·전화·이메일·로고 이미지·견적 조건 문구·유효기간 기본값 저장
4. **문서 목록 관리** — 생성된 견적서/보고서의 다시 보기·다운로드(PDF/HTML)·삭제

## 기술 스택

| 구분 | 내용 |
|------|------|
| 백엔드 | Python 3.12, Flask 3 |
| 저장소 | SQLite (서버 내 `data/app.db`, 별도 DB 설치 불필요) |
| 데이터 분석 | pandas, openpyxl (Excel 읽기) |
| 차트 | matplotlib → PNG (base64 인라인, 한글 폰트 Noto Sans CJK) |
| PDF 생성 | **WeasyPrint (로컬 변환)** — HTML/CSS를 그대로 PDF로 렌더링하므로 화면과 동일한 양식 출력. 외부 API 호출 없음 |
| 프론트엔드 | 서버 렌더링 Jinja2 + 바닐라 JS (빌드 과정 없음), 반응형 CSS |

## 정식 구축 시 확장 방안

시연용 프로토타입을 실제 납품 수준으로 확장할 때의 로드맵입니다.

1. **전자결재 연동** — 견적서 생성 → 결재선 지정 → 승인/반려 워크플로우. 결재 완료 시 PDF에 전자서명·승인일시 자동 삽입
2. **ERP/회계 연동** — 더존·SAP·영림원 등 ERP의 품목 마스터·거래처 정보와 동기화, 확정 견적을 수주/매출전표로 자동 전환
3. **권한·감사(audit)** — 부서별/직급별 문서 접근 권한, 누가 언제 무엇을 생성·수정·다운로드했는지 이력 추적
4. **템플릿 버전 관리** — 견적서 양식의 버전별 관리와 변경 이력, 다국어(영문) 양식 지원
5. **대량 처리·스케줄** — 월말 정산 보고서 자동 생성·이메일 발송, API 제공으로 타 시스템에서 호출 가능
6. **인프라** — WSGI(gunicorn) + 리버스 프록시 구성, 백업·암호화 저장, 개인정보 마스킹

## 타겟 단가대 근거 (1,500~3,000만원)

- **수요 근거**: 국내 AI 의뢰 시장에서 문서·데이터 자동화 분야가 약 20%로 2위 규모 —
  중소기업이 "도입 즉시 체감하는 ROI" 영역이라 발주 전환율이 높음
- **공수 산정**: 위 확장 방안(전자결재·ERP 연동·권한/감사) 포함 시 통상 2~3인 × 6~8주 규모.
  위시켓 기준 유사 프로젝트(업무 자동화·백오피스 시스템)의 낙찰가 분포가 1,500~3,000만원대에 형성됨
- **데모 포지셔닝**: 본 프로토타입은 핵심 가치(입력→자동 계산→정식 문서 출력)를 5분 안에 증명하는
  영업용 자산이며, 실제 견적 시 위 확장 항목을 옵션으로 제시해 단가를 설계

## 알려진 제한 (솔직한 고지)

- 동시 다중 사용자·로그인을 가정하지 않은 단일 사용자 데모입니다.
- PDF 변환에 WeasyPrint를 사용하므로, 설치 환경에 시스템 라이브러리(pango/cairo)가 필요합니다.
  (`run.sh` 실행 환경에는 포함되어 있음)
- 차트는 정적 PNG이며 인터랙티브(drill-down 등) 기능은 없습니다 — 정식 구축 시 확장 항목입니다.
